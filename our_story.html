About Our Blog

Cricket Pulse is a fan-focused blog dedicated to celebrating the sport of cricket in Australia. We chose this theme because cricket holds a special place in Australia’s national identity, with a rich history, passionate fanbase, and countless international achievements. Australia is the most successful team in the history of the ICC Men's Cricket World Cup, having won the title six times — in 1987, 1999, 2003, 2007, 2015, and most recently in 2023. From the golden era of Sir Donald Bradman, to the dominance of Ricky Ponting’s squad, and now the leadership of Pat Cummins, Australian cricket continues to inspire generations. Our blog captures that passion through a clean and user-friendly platform where fans can read posts, browse archives, register or log in, and contribute their own content via a write post page. The site is composed of several functional pages: the homepage for latest content, older.html for past posts with reveal/hide animation, login.html and register.html for user interaction, and write.html for content submission. We developed everything using raw HTML5, CSS, and JavaScript without any libraries or frameworks, ensuring full control and alignment with accessibility and coding standards taught in our unit. The goal was to deliver an engaging, responsive, and inclusive digital space where cricket enthusiasts can connect, contribute, and enjoy the game online.

HD Extensions Implemented

  • Responsive Design: The layout adjusts smoothly across different screen sizes using CSS flex-wrap, percentage-based widths, and max-widths on containers. Elements such as forms, banners, and navigation adapt seamlessly to both desktop and mobile devices.

  • Sticky Navigation Bar: The navigation bar remains visible at the top of the screen as the user scrolls, improving access to other pages and enhancing user experience. This was achieved using position: sticky and proper z-index layering.

  • Scroll-to-Top Button: A circular button appears after scrolling 200px and lets users smoothly return to the top of the page. This helps navigation on longer pages such as Older Posts.

  • Animated Reveal/Hide of Blog Posts: On the Older Posts page, users can click “Read More” or “Hide” to expand or collapse post content with smooth transitions using CSS and JavaScript.

  • Light/Dark Mode Toggle: A theme toggle button allows users to switch between light and dark modes. The choice is saved using localStorage so the preference persists across sessions.

  • Password Show/Hide Toggle: On the Login and Register pages, users can toggle the visibility of their password using a custom button, enhancing usability without breaking validation logic.

  • Cricket-Themed Banner: In addition to the required site logo, we added a cricket-themed banner image on every page for stronger visual appeal and thematic consistency.

Development Log

  • 04-04-2025 (Syed): The homepage (index.html) was developed as the main landing page of our blog project. It features three blog posts displayed in reverse chronological order, with each post containing a title, author, creation date (day/month/year), at least 150 words of content, and a list of tags. We used semantic HTML5 elements like <main> and <article> to clearly define the page structure, enhancing both readability and accessibility. The page layout was styled using raw CSS, and the footer was added for a consistent closing section across all pages.

    Visually, we implemented a cricket-themed banner image with a site logo positioned at the top-right using position: absolute and z-index. The site title “Cricket Pulse” was layered over the banner using translucent background and text-shadow for contrast. The navigation bar, placed directly under the header, includes links to all site pages and features interactive :hover styling and an .active class to highlight the current page. All structural containers use max-width and margin: auto to maintain balance on larger screens, while flex-wrap in the navigation ensures layout stability on smaller viewports. Initially, the logo overlapped the banner text on mobile screens, but we resolved this by adjusting image size and padding.

  • 04-04-2025 (Billal): The older.html page was created to display five additional cricket blog entries that are not featured on the homepage. Each blog post includes a clear title, author, date (day/month/year), tags, and long-form content hidden by default. We used semantic HTML5 tags like <article> and <main> to structure the posts, ensuring the page remains consistent with the overall site layout. A cricket-themed banner with the site logo was reused at the top, and the navigation bar highlights the active page using the .active class.

    The core functionality added was the ability to reveal or hide each post's full content using “Read More” and “Hide” buttons. This was implemented using a custom JavaScript function in main.js, which toggles the .hidden class on the content container. We styled the toggle effect with CSS to ensure the layout remains clean when expanded. One problem we faced was ensuring the buttons worked independently per post — this was fixed by correctly scoping each toggle to its parent <article>. We also ensured the design matched the homepage with proper spacing, typography, and responsive structure.

  • 05-04-2025 (Oishe): The login.html page was created to provide users with access to member-only features of the blog. It includes a login form with labeled input fields for both username and password, styled using raw CSS to maintain consistency with the rest of the site. The layout includes a welcome tagline, a “Register” link for new users, and a reusable banner and navigation bar where the “Login” link is highlighted using the .active class.

    Functionality was added using JavaScript to validate that both fields are filled before allowing form submission. If either field is empty, the form highlights the invalid input with a red border and displays an error message below. Upon successful validation, the user is redirected to the homepage. A “Show/Hide Password” toggle button was also implemented as an HD extension, allowing users to view or mask their password input. A challenge we encountered was ensuring the error messages cleared properly on re-entry — this was fixed by resetting validation classes and message content on each submit attempt. All logic was handled via main.js, with no frameworks used.

  • 05-04-2025 (All Group Members): The register.html page was developed as a dedicated registration interface for new users joining the Cricket Pulse blog. The form includes labeled input fields for username, email, password, and confirm password, along with “Register” and “Reset” buttons. We maintained site-wide design consistency by reusing the banner, logo, navigation menu (with the "Register" link highlighted), and semantic HTML5 structure. A short tagline encourages user sign-up, while layout styling was handled using raw CSS.

    JavaScript was used to validate several conditions before allowing form submission: empty fields, invalid email format, mismatched passwords, and non-compliance with our password policy (minimum 8 characters, including uppercase, lowercase, digit, and special character). Visual feedback was added using red borders on invalid inputs and multi-line error messages. The form resets when the reset button is clicked, and valid submissions redirect to the homepage. As a High Distinction extension, we implemented a show/hide toggle for both password fields. We initially faced a bug where the confirm password did not validate correctly if the password field was invalid — this was resolved by ordering validations and clearing previous error styles at the start of each submission check.

  • 06-04-2025 (Hasan): The write.html page was created to allow users to compose and submit new blog posts to the Cricket Pulse site. The form includes labeled input fields for the blog title, tags/keywords, and a large textarea for the main content. A "Publish" button submits the post, while a "Reset" button clears all fields. The layout incorporates our reusable banner, navigation bar (with the "Write" link highlighted), and follows semantic HTML5 structure for accessibility and consistency across the site. Styling was handled using raw CSS, and a tagline encourages user contributions.

    JavaScript was implemented to validate user input before submission. Validation rules include checking for empty fields and ensuring the blog title does not exceed 80 characters. If invalid, the affected input or textarea is highlighted with a red border, and an appropriate multi-line error message is displayed beneath the form. On successful validation, the user is redirected to the homepage. We encountered an issue where content validation wasn't applying red borders to the textarea — this was fixed by assigning the .invalid class directly to the <textarea> tag in the script. All form logic was handled using raw JavaScript in main.js without relying on third-party libraries.

  • 06-04-2025 (All Group Members): High Distinction Extensions were added across all pages to enhance usability, interactivity, and responsiveness. Below are five enhancements we implemented:

    1. Responsive Design: We ensured the site remained fully responsive across all screen sizes using flexible units like width: 100% for banners and max-width with margin: auto for forms and content blocks. The nav bar used flex-wrap to wrap links on mobile. No issues were encountered, but we tested thoroughly on various screen sizes to confirm layouts didn't break.

    2. Sticky Navigation Bar: We made the navigation bar sticky by moving it outside of the <header> and applying position: sticky in CSS. This ensures the nav stays fixed at the top during scrolling. At first, placing the entire header as sticky caused the banner and logo to overlap, but moving only <nav> outside the header resolved this cleanly.

    3. Scroll-to-Top Button: A scroll-to-top button was added using JavaScript to detect scroll position and CSS to fix its placement. It appears after scrolling 200px and performs a smooth scroll when clicked. Initially, it didn't appear due to CSS display: none being permanent; this was fixed by toggling display through JS on scroll events.

    4. Smooth Post Reveal Animation: We enhanced the post toggle feature by animating the reveal/hide of post content using a combination of opacity and max-height transitions. The animation didn't work at first because the .revealed class was added too quickly — this was fixed using a 10ms timeout to separate display changes and animation trigger.

    5. Dark/Light Theme Toggle: We implemented a dark mode toggle that switches theme styles across the site. User preferences are saved in localStorage. A button was added after the banner in each page's header. One challenge was ensuring dark mode didn’t affect visibility of form taglines and buttons — resolved by customizing styles specifically for dark mode using body.dark-mode selectors.

The page introduces all four group members, explains the purpose behind choosing a cricket-focused theme, and itemizes the High Distinction (HD) extensions we implemented. It also includes a reference list for all external assets and a detailed record of development milestones.
